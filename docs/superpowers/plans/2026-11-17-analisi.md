# Analisi d'uso con tgram-analytics — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** la build di produzione manda a tgram-analytics pochi eventi anonimi (voli, guasti, salvataggi, menu), spegnibili dalle Impostazioni.

**Architecture:** una feature `lib/features/analytics/` con i livelli dello starter (domain senza Flutter né Riverpod, data, application); la sezione delle Impostazioni resta in `lib/app/presentation`.
- un'interfaccia `Analytics` con due versioni, `TgramAnalytics` e `NoAnalytics`, scelte da un provider in base alla chiave di compilazione e all'interruttore;
- tutti i nomi e le proprietà degli eventi in un solo file (`AppEvent`);
- la radio è osservata da fuori con una funzione pura (prima, dopo) → eventi; salvataggi e menu chiamano l'evento dopo il successo.

**Tech Stack:** Flutter, Riverpod (generatore), `tgram_analytics: ^0.2.0` (MIT), `package:http/testing.dart` nei test.

**Spec:** `docs/superpowers/specs/2026-11-17-analisi-design.md`

## Global Constraints

- **Nomi degli eventi**, esatti:
  - `app_opened`, `welcome_completed`;
  - `flight_started`, `flight_landed`, `flight_failed`, `playback_broken`;
  - `favorite_added`, `favorite_removed`, `song_saved`, `song_removed`;
  - `song_search_opened`, `song_copied`, `station_retuned`.
- **Proprietà**, esatte:
  - `kind` ∈ `forward|back|reconnect`; `attempts` (int, ≥ 1);
  - `country` (codice ISO della stazione); `station` (nome della stazione); `codec` (`station.codec`, oppure `unknown` se manca o è vuoto);
  - `service` ∈ `spotify|youtube|amazon_music|web`; `first_open` (bool).
- **Proprietà della sessione** (`TGA.identify`): `app_version`, `locale` (`it`/`en`), `theme` (`system`/`light`/`dark`), `android_sdk` (int, 0 se ignoto).
- **Mai testo dell'utente** nelle proprietà: niente titoli, artisti o query di ricerca.
- **Sessione:** 32 caratteri esadecimali da `Random.secure()`, una per avvio, solo in memoria.
- **Chiavi:** `--dart-define` `TGA_API_KEY` e `TGA_SERVER_URL`, senza valori predefiniti. Le analisi sono attive solo se la chiave inizia con `proj_` e l'URL con `https://`.
- **Interruttore:** preferenza `app.analyticsOn`, predefinita `true`. Se le preferenze non si leggono, le analisi sono spente.
- **Spento = nessuna chiamata a `TGA`**, nemmeno in coda.
- **Un errore delle analisi non esce mai** da `track` e non ritarda la radio.
- **Testi:**
  - IT: «Privacy», «Statistiche anonime», «Aiutano a capire cosa non funziona. Nessun dato su di te.», «Informativa sulla privacy»;
  - EN: «Privacy», «Anonymous statistics», «They help find what doesn't work. Nothing about you.», «Privacy policy».
- **Informativa:** `https://davidetarsi.github.io/frequenza/privacy.html`.
- **Verifica di fine task:** `bash tool/check.sh`.

## Review Focus

1. **Interruttore spento mentre l'app è aperta:** l'evento successivo non parte. Test nel Task 1.
2. **Server irraggiungibile o lento:** nessuna eccezione, e la radio non aspetta. Test nel Task 1, con un client che lancia o non risponde.
3. **Lo stesso volo dalla notifica e dalla manopola:** un solo `flight_started` per passaggio di stato. Test nel Task 2.
4. **Stazione con `codec` nullo o vuoto:** `codec: unknown`. Test nel Task 1.
5. **Preferenze illeggibili:** analisi spente, e l'app si apre normalmente. Test nel Task 1.

**Limite accettato:** due giri di manopola nello stesso primo tentativo producono uno stato identico, quindi contano come un volo solo. Il codice della radio non si tocca per contarli.

**Interfaces:**
- Produces:
  - `final class AppEvent { const AppEvent(this.name, [this.properties = const {}]); final String name; final Map<String, Object> properties; }`, con `==`/`hashCode` sui due campi e i costruttori con nome:
    - `appOpened({required bool firstOpen})`, `welcomeCompleted()`;
    - `flightStarted(FlightKind kind)`;
    - `flightLanded(RadioStation station, {required FlightKind kind, required int attempts})`;
    - `flightFailed({required FlightKind kind, required int attempts})`;
    - `playbackBroken(RadioStation station)`;
    - `favoriteAdded(RadioStation)`, `favoriteRemoved(RadioStation)`, `songSaved(RadioStation)`, `songRemoved(RadioStation)`;
    - `songSearchOpened(SearchService)`, `songCopied()`, `stationRetuned()`.

    `SearchService.amazonMusic` diventa `amazon_music`: il nome in snake_case.
  - `abstract interface class Analytics { void track(AppEvent event); void describeSession(Map<String, Object> properties); }`
  - `final class NoAnalytics implements Analytics`: non fa nulla.
  - `final class TgramAnalytics implements Analytics`:
    - costruttore `TgramAnalytics({required String apiKey, required String serverUrl, required String sessionId, http.Client? client})`;
    - chiama `TGA.init` una sola volta, alla prima chiamata;
    - `track` → `TGA.track(name, sessionId, properties:)` e `describeSession` → `TGA.identify`, entrambi dentro `try/catch`.
  - `typedef AnalyticsKeys = ({String apiKey, String serverUrl})` e `bool analyticsKeysComplete(AnalyticsKeys keys)`.
  - Provider:
    - `analyticsKeysProvider` (keepAlive), che legge `String.fromEnvironment`;
    - `analyticsSessionIdProvider` (keepAlive, `String`);
    - `analyticsConsentProvider` (keepAlive `AsyncNotifier<bool>`, con `Future<bool> select(bool on)`, sul modello di `AppThemeMode` con `LatestSave`);
    - `analyticsProvider` (keepAlive, `Analytics`).
  - `class RecordingAnalytics implements Analytics { final events = <AppEvent>[]; final session = <String, Object>{}; }`, nei test.
